# Clean Design Experiment

Branch: `experiment/clean-home-design`

When **Profile → Developer → Clean design experiment** is on (default on this branch):

- **Home** — Solace-style 2×2 shell (`CleanHomeView`)
- **Chat / Chaplain** — Clean palette + Open Runde on hub and full-screen chat
- **Journal / Profile** — same palette/type cascade via `sanctuaryPalette` + `AppFont`
- **Streak** — `CleanStreakView`
- **Tab bar** — floating Solar Duotone pill (Home · Journal · Chat · Profile)
